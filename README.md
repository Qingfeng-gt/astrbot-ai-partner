# astrbot_plugin_hanhan — 憨憨人格

一个自包含的 AstrBot 人格插件：把前任"憨憨"做成 bot。人格由 Claude Code 的 `/create-ex` skill（前任蒸馏）生成——该 skill 产出"关系记忆 + 人物性格 + 运行规则"的完整人格设定，本插件将其**浓缩为单一 md 提示词**（`persona/persona_prompt.md`）运行。整个项目不依赖仓库外的任何文件，克隆即用。

## 两种用法

### 方式 A：粘贴人格（任何版本都适用，推荐先试这个）

1. 打开 AstrBot 后台 → **服务配置** → LLM 提供商 → **人格与情景**
2. 把 [`persona/persona_prompt.md`](persona/persona_prompt.md) 的全部内容粘贴进去，保存
3. 重启会话生效

### 方式 B：插件自动注入（每个会话生效，可随时开关）

1. 把整个 `astrbot_plugin_hanhan/` 文件夹复制到 AstrBot 的插件目录：
   - 3.x：`AstrBot/data/plugins/astrbot_plugin_hanhan/`
   - 4.x / 新版本：`addons/` 目录（或后台"插件管理"里安装本地插件）
2. 重启 AstrBot（或在后台启用插件）
3. 命令：
   - `/憨憨开关` — 按会话切换人格开关
   - `/憨憨状态` — 查看当前会话开关状态

## 表情包（按情绪）

1. 把表情包图片丢进 `astrbot_plugin_hanhan/stickers/`（支持 png / jpg / jpeg / gif / webp / bmp）
2. **文件名里带上情绪关键词**（如 `catbug-开心.webp`、`catbug-无语.webp`），憨憨会根据当下情绪输出 `[表情包:情绪词]`（如 `[表情包:开心]`），插件按文件名关键词匹配最贴合的一张发送
3. 匹配不到时依次尝试情绪同义词表（如"无语"→呕吼/思考中/不要）→ 最后随机兜底
4. **防刷屏**：每轮回复最多 1 张表情包，10 分钟内最多 3 张；同一张不会连续重复出现
5. 图片随用随扫，丢进去就能用，无需重启

## 发送机制（真实感）

- **分条发送**：模型输出的一行 = 一条消息。两句话会自动拆成两条依次发送，偶尔会出现一个字单独一条（"嗯"）再跟后面的内容
- **结尾无句号（硬保证）**：人格提示词里"禁止句号"是硬规则，且插件侧还会自动删除每条消息结尾的单句号（`。。。`、`。。` 等省略式保留）
- `[表情包:情绪词]` 单独一行 = 只发表情包；跟在文字后 = 先发文字再发表情包

## 智能行为（情景感知）

每轮 LLM 请求前，插件注入一段【情景感知】提示，让憨憨对当前气氛敏感：

- **话题突变**：你突然换了话题（与上一条消息重叠度低且在 10 分钟内），她会先"啊？""啥？"或发疑问/思考中的表情包，反应过来了才接新话题
- **久别**：隔 2 小时以上再联系，语气不热络；隔 12 小时以上，淡淡的、像刚想起来回消息
- **忙碌节奏**：她说过"去忙/睡了/上课"之后 2 小时内，回复按自己的节奏，不秒回
- **遗忘**：上下文超过 30 条自动截断更早的对话，并提示她"更早的事记不清了"——被问到旧细节会模糊、不确定
- **时间感知**：每轮注入当前时间 + 时段提示（深夜放下防备、白天忙里偷闲）；身份阶段由函数取当前日期与**人格提示词里的【时间线】表**比较得出（时间节点不写死在代码里，改表即改推算）

## 消息支持

- **人格只在私聊会话生效**（前任人格在群里不合适）：群聊消息走 AstrBot 默认回复，不注入人格、不拆分、不发表情包
- 私聊判断在钩子内部完成（AstrBot 的 LLM 钩子调度不检查 `@event_message_type` 过滤器，这是 v4 的实现特性）
- 想允许群聊也启用：把 `main.py` 里的 `_PERSONA_ONLY_PRIVATE = True` 改成 `False`

## 模块结构（多文件）

```
astrbot_plugin_hanhan/
├── main.py              # 编排层（必须根目录）
├── metadata.yaml        # 插件元数据（必须根目录）
├── core/                # 业务逻辑包
│   ├── __init__.py
│   ├── persona_loader.py    # 人格提示词加载
│   ├── reply_processor.py   # LLM 回复解析（分条/去句号/表情包标记）
│   ├── sticker_bot.py       # 表情包选择（情绪匹配/同义词/防重复/限频）
│   └── memory_engine.py     # 情景感知（时间/阶段/话题突变/遗忘/忙碌）
├── persona/
│   └── persona_prompt.md    # 人格提示词（单一 md，可自行编辑）
├── stickers/            # 表情包文件夹（用户直接管理）
└── README.md
```

## 自定义

- 人格内容全部在 `persona/persona_prompt.md`（单一 md 提示词，独立文件夹），直接改，改完重启 AstrBot（或重启会话）生效
- **时间线（身份阶段）**：推算表在 `persona/persona_prompt.md` 的【时间线】章节（`| 时间段 | 身份状态 |` 格式），插件每轮读表并按当前日期匹配；改表即调整推算，**无需改代码**。支持单月、区间（`~`/`至`）、开区间（`之前`/`及以后`）
- **换一个人格**：用 Claude Code 的 `/create-ex` skill 生成新前任的人格（该 skill 输出关系记忆 + 人物性格的完整设定），再将其浓缩为单一 md 提示词替换 `persona/persona_prompt.md`；表情包情绪词表在 `core/sticker_bot.py` 的 `EMOTION_TO_KEYWORDS` 里，可同步调整

## 兼容性说明

- 本插件按 AstrBot **新版插件格式**编写：`metadata.yaml` 声明元数据 + `Star` 子类自动注册（v3.5.20+ 起不再需要 `@register`）
- 若用的是 AstrBot v3.5.20 之前的旧版，在类上手动加回 `@register(name, author, desc, version)` 装饰器即可
- 若用的是进程隔离的 `astrbot-sdk` v4 架构（清单文件为 `plugin.yaml`），请改用方式 A 粘贴人格，或改写为对应钩子
